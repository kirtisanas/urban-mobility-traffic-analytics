# Urban Mobility & Traffic Analytics

## Project Overview

Urban Mobility & Traffic Analytics is a SQL-based data analytics project
designed to analyze transportation routes, trips, traffic levels, travel
times, and traffic delays.

The project uses a relational database containing three tables:
Routes, Trips, and Traffic.

## Tools & Technologies

- MySQL
- SQL
- Power BI
- Excel

## Database Tables

### Routes
Contains route information:
- Route ID
- Route Name
- Start Location
- End Location
- Distance

### Trips
Contains:
- Trip ID
- Route ID
- Trip Date
- Trip Time
- Vehicle Type
- Travel Time

### Traffic
Contains:
- Traffic ID
- Route ID
- Date
- Peak Hour
- Traffic Level
- Delay Minutes

## SQL Analysis

The project uses:

- SELECT
- WHERE
- COUNT
- AVG
- MIN / MAX
- GROUP BY
- ORDER BY
- HAVING
- JOIN
- Subqueries
- CASE Statements
- Window Functions
- RANK()

## Key Analysis

The project analyzes:

- Route performance
- Average travel time
- Traffic delays
- Vehicle usage
- Busiest routes
- High-delay routes
- Traffic-level distribution
- Route ranking based on traffic delay

## Project Objective

The objective is to analyze urban transportation data using SQL
and identify useful patterns related to route performance,
travel time, and traffic conditions.
